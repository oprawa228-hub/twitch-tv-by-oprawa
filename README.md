# Twitch TV by Oprawa

Twitch для телевизора и пульта: подписки в эфире, игры, поиск, записи и чат. Основа — [SmartTwitchTV](https://github.com/fgl27/SmartTwitchTV), Android-плеер Media3 сохранён.

## Установка

**[Скачать APK](https://github.com/oprawa228-hub/twitch-tv-by-oprawa/releases/latest/download/Twitch-TV-by-Oprawa-test.apk)** · [Версии и изменения](https://github.com/oprawa228-hub/twitch-tv-by-oprawa/releases)

Передайте APK на Android TV / YaOS и откройте установщиком. Для входа отсканируйте QR на экране и введите код Twitch на телефоне. Устанавливайте поверх прежней тестовой сборки без удаления, чтобы сохранить аккаунт и историю. Пакет `com.oprawa.twitchtv.test`.

## Обновления

С версии **3.0.379-oprawa.9**: **Настройки → О приложении и управление → Проверить обновления**. Приложение также проверяет канал при запуске не чаще раза в сутки и сообщает о новой версии. Установка подтверждается пользователем в системном окне Android; может понадобиться разрешение установки для Twitch TV by Oprawa.

Перед установкой проверяются SHA256, размер, пакет, номер версии и совпадение подписи с установленным приложением. С V8 и более старых версий сначала один раз установите текущий APK вручную.

Для уведомлений GitHub: **Watch → Custom → Releases**. Ссылку на эту страницу можно отправлять знакомым.

## Возможности и совместимость

Подписки на старте, быстрые каналы онлайн, записи с продолжением и скоростью, чат рядом/поверх видео, глобальные часы, таймер сна, компактные настройки, D-pad/OK/Back. Нативное воспроизведение Media3.

Это неофициальный клиент, не связанный с Twitch. Тестовый канал. Проверки выполняются в Chromium и Android TV эмуляторе; конкретные ограничения указаны в описании версии. Физический YaOS и настоящий аккаунт требуют пользовательской проверки.
